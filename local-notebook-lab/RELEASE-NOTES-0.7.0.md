# Local Notebook Lab 0.7.0

- VS Code를 참고한 메뉴·활동 표시줄·탐색기·편집기 탭 배치
- 다크·라이트·시스템 테마와 글꼴·줄바꿈·자동 저장 설정
- 명령 팔레트·빠른 파일 이동·노트북 코드 검색
- VS Code 방식의 단축키와 Ctrl+K 연속 키 지원
