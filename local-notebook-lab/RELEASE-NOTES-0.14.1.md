- 더 보기 아이콘을 실제 말줄임표로 표시
- RAM / GPU 표기와 정보 문구 정리
- 사용자 노트북 원문, 수식, 실제 패키지 배포 설명 유지
- 0.14.0의 파일 정리, 환경 재구성, 자원 표시, 셀 작업, 단축키 기능 포함

기본은 경량 노트북 환경이며 딥러닝 패키지를 포함하지 않습니다. 처음 설치는 Setup EXE를 사용합니다. 경량 버전용 Update EXE는 같은 경량 환경의 기존 앱에 적용하며, 구 대용량 환경은 0.6.0 경량 전환 경로를 유지합니다.


이전 기능과 검증

## 0.14.0 누적 기능

0.10.0 이후 누적 변경을 포함합니다.

- 파일 이동, 앱 휴지통 보관, 덮어쓰기 없는 복원
- 환경 명세 가져오기, 기존 요구사항 합치기/구성 교체, 실제 설치 진행과 취소
- 실제 PC RAM, 프로젝트 커널 메모리, 전체 GPU 상태 조회
- 여러 셀 선택, 이동, 노트북 간 복사, 사용자 단축키와 충돌 검사
- 전체 PyPI 이름 검색, 최신/호환 버전 선택, 누락 패키지 일괄 설치 안내
- 좌측 중복 목록 제거, 더블클릭 열기, 우클릭 이름 변경/복제/옆으로 열기
- 프로젝트 폴더별 새 창, 범위 실행, 셀 접기/분할/합치기, 수식/이미지/HTML 보고서
- 기본76개 경량 환경과 기존 노트북, 설정, 추가 패키지 보존

기본 Python/Jupyter76개를 유지합니다. 딥러닝 라이브러리는 앱에서 선택 설치합니다. GPU 수치는 전체 장치 기준입니다. 앱 휴지통은 Windows 휴지통과 별개이며 자동으로 비우지 않습니다. 환경 변경 후 커널 재시작은 사용자가 선택합니다.

86개 검증과 분리된 시험 AppId의 실제0.13.2→0.14.0 업데이트 시험을 통과했습니다. 새 PC, 다른 GPU에서의 학습 시험을 의미하지 않습니다.

처음 설치는 Setup EXE, 기존 경량 앱은 설정 → 업데이트에서 수동 확인합니다. 자동 확인은 기본 꺼짐입니다. 구 대용량 환경용0.6.0 경량 전환 피드는 유지합니다.


0.14.1은 자체 UI 문구 수정이며 사용자 노트북과 수식을 일괄 수정하지 않습니다. 실제0.14.0에서0.14.1로의 분리 업데이트 시험과 패키징 UI 확인을 수행합니다.
