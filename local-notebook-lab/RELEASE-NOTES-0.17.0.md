# Local Notebook Lab 0.17.0

- 누락 패키지 검사와 버전 선택, 실제 의존성 검사 후 일괄 설치
- 패키지별 다운로드 진행, 실제 설치 순서와 최종 검증 완료 상태 표시
- 직접 입력하는 PowerShell 터미널, 앱 Python과 프로젝트 폴더 연결
- 설치 로그와 터미널 탭 전환, Ctrl+C 중단, Ctrl+` 열기
- 셀 진행률은 같은 자리에서 갱신하고 일반 로그와 에폭 결과는 보존
- Python 구문 색상, 노트북과 분할 화면 및 Python 파일에 일관되게 적용
- 파일 목록 Delete 키와 우클릭 삭제, 확인 후 앱 휴지통 보관
- 기존 노트북, 추가 패키지, 설정과 경량 기본76개 환경 보존

기본은 경량 노트북 환경이며 딥러닝 패키지를 포함하지 않습니다. 처음 설치는 Setup EXE를 사용합니다. 경량 버전용 Update EXE는 같은 경량 환경의 기존 앱에 적용하며, 구 대용량 환경은 0.6.0 경량 전환 경로를 유지합니다.
